# Development Setup

## Prerequisites

- Node.js
- npm

## Frontend

The Next.js application is maintained in the `frontend/` directory.

To run it locally:

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Current Scope

The repository currently contains the project overview and the initial frontend foundation. The customer-facing interface is the next development milestone.

Backend services, database integration, and deployment configuration will be documented here when those decisions are finalized.

## Git Workflow

Keep changes focused and use descriptive commit messages. Do not commit local dependencies, build output, or environment files.
