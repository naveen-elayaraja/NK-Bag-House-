# Contributing to NK Bag House

Thank you for helping improve the NK Bag House website project.

This repository currently contains a business website project and proprietary project materials. It is not an invitation to reuse the code, branding, product images, or content. Please coordinate with the repository maintainer before starting substantial work or submitting a pull request.

## Before making changes

1. Check existing issues and project documentation.
2. Confirm the intended change with the maintainer.
3. Keep each change focused and explain the customer or engineering problem it solves.
4. Do not add unapproved product specifications, customer details, brand assets, or business claims.

## Development workflow

- Work on a descriptive branch rather than committing experimental changes directly to the production branch.
- Use clear commit messages, such as `feat: add product category navigation` or `fix: improve enquiry form validation`.
- Keep dependencies purposeful; do not add a package for a feature that can be implemented cleanly without it.
- Do not commit `.env` files, credentials, build output, or `node_modules`.
- Preserve existing third-party licence notices and include required attribution for assets.
- Run relevant lint, type-check, and production build commands before requesting review.

## Pull requests

A pull request should explain:
- What changed.
- Why the change is needed.
- How it was tested.
- Any environment variables or migration steps required.
- Screenshots or a short recording for visible UI changes.
- Accessibility and responsive behaviour checked.

Keep pull requests small enough to review. Do not include unrelated formatting or generated files.

## Design and content expectations

- Follow `docs/UX_DIRECTION.md` and `docs/DESIGN_SYSTEM.md`.
- Use approved NK Bag House assets only.
- Do not imitate a reference brand's protected visual identity.
- Verify every published product specification and business claim.
- Design for mobile, keyboard access, and readable content.

## Licensing

The project uses a proprietary rights notice pending rights-holder approval. A contribution must not be assumed to grant permission to reuse the wider project. Confirm ownership and any contributor terms with the maintainer before contributing original code or assets.

## Questions

For project coordination, contact the repository maintainer through the contact method they have verified and published. Do not put private customer or business information in public issues.
